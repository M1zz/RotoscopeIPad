Palang Book プライバシーポリシー

施行日：2026年10月16日（旧版：2026年10月13日）

概要：Palang Book は個人情報を収集しません。
アカウントも、独自のサーバーも、広告も、追跡もありません。お子さまが描いた絵や録音した声は、すべてお使いの端末の中だけに保存されます。外部に送られるのは、誰のものかわからない匿名の利用統計（下記5）と、保護者の方が「フィードバックを送る」からご自身で送ったご意見だけです。

1. 収集する情報

個人情報は収集しません。Palang Book は、名前、メールアドレス、位置情報、広告識別子など、利用者やお子さまを特定できる情報を収集せず、描いた絵や動画、録音を端末の外に送ることもありません。アプリにはログインや会員登録の機能はなく、広告の SDK や外部の分析サービスも含まれていません。端末の外に送られるのは、下記5の匿名の利用統計と、ご自身で送るフィードバック（下記4）だけです。

2. 端末の権限を使う理由

権限利用目的データの保存場所
カメラなぞって描く動画を撮影するとき端末内のアプリ領域
写真ライブラリ（読み取り）なぞって描く動画を読み込むとき端末内のアプリ領域
写真ライブラリ（追加）完成したアニメーションを動画として保存するときお使いの「写真」アプリ
マイクアニメーションにお子さまの声を録音（アフレコ）するとき端末内のアプリ領域

各権限は、その機能を使うときにだけ求められます。許可しなくても、ほかの機能はそのまま使えます。権限を通じてアクセスした内容が端末の外に送られることはありません。

3. インターネット接続

インターネットに接続するのは次の場合だけです。リンクから動画を開くときにその動画をダウンロードする場合、買い切りプランの購入・復元のために Apple の App Store を利用する場合、フィードバックを送る場合（下記4）、そして匿名の利用統計を送る場合（下記5）です。動画のダウンロードはお使いの端末と動画のサーバーとの間だけで行われ、開発者を含む第三者に情報が渡ることはありません。ダウンロードした動画は端末の中だけに保存され、プロジェクトを削除すると一緒に削除されます。支払いはすべて Apple が処理し、開発者がお支払い情報を受け取ることはありません。

4. フィードバックの送信

サポート画面の「フィードバックを送る」からご意見を送ると、入力した内容（ご意見の種類、メッセージ、添付したスクリーンショット、返信用に入力したお名前・メールアドレス）と、アプリのバージョン、機種、OS のバージョン、言語設定が、Apple の iCloud（CloudKit）を通じて開発者に届きます。返信とアプリの改善にのみ使用し、送信しない限り何も送られません。お名前とメールアドレスの入力は任意です。送ったフィードバックの削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。フィードバックは保護者の方が送ってください。

5. 匿名の利用統計とエラーレポート

アプリをよりよくするため、Palang Book は次の匿名の統計を Apple の iCloud（CloudKit）に送信します。この記録を見られるのは開発者だけで、アプリの改善以外の目的に使ったり、第三者に渡したりすることはありません。

  • インストール時に作られるランダムな ID（利用者、Apple ID、端末、ほかのアプリとは結びつかず、アプリを削除して再インストールすると変わります）
  • アプリのバージョン、OS のバージョン、地域と言語の設定
  • アプリを起動した回数、アプリを開いた日、インストールした日
  • アプリ内で起きた出来事の名前（満足度の質問やレビューのお願いが表示されたか、買い切りプランの画面の表示・購入・復元の各段階など。お支払い情報は含まれません）
  • アプリが強制終了したり固まったりしたときのエラーレポート（機種と技術的な診断情報）

名前、連絡先、位置情報、描いた絵・動画・録音などの作品は、この統計に含まれません。統計は端末が iCloud にサインインしているときだけ送信され、サインインしていなければ何も送られません。

6. 子どもの保護

Palang Book は、子どもが使うことを前提に作られています。子どもを含め、どなたの個人情報も収集しません。収集するのは上記5の匿名の統計だけで、そこからお子さまが誰なのかを知ることはできません。広告、追跡、ソーシャル機能はありません。唯一のアプリ内課金である買い切りプランは、子どもがひとりでは通れない大人向けの確認（計算問題）の先にあります。

7. データの削除

描いた絵や動画、録音は端末の中だけにあるため、アプリ内でプロジェクトを削除するか、アプリを削除すればすべて削除されます。匿名の利用統計は利用者と結びつかないため、特定の方の記録を探し出すことはできません。アプリを削除して再インストールすると新しいランダムな ID が作られ、以前の記録はお使いの端末とつながらなくなります。ご自身で送ったフィードバックは、上記4のとおりご依頼があれば削除します。

8. ポリシーの変更

このポリシーを変更する場合は、このページに掲載し、施行日を更新します。
