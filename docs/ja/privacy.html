Palang Book プライバシーポリシー

施行日：2026年10月13日（旧版：2026年7月11日）

概要：Palang Book は個人情報を収集しません。
アカウントも、独自のサーバーも、広告も、分析ツールもありません。お子さまが描いた絵や録音した声は、すべてお使いの端末の中だけに保存されます。外部に送られるのは、保護者の方が「フィードバックを送る」からご自身で送ったご意見だけです。

1. 収集する情報

ありません。Palang Book は、名前、メールアドレス、位置情報、利用履歴、広告識別子など、いかなる個人情報も自ら収集・送信・保存しません。アプリにはログインや会員登録の機能はなく、分析（アナリティクス）や広告の SDK も含まれていません。ご自身で送るフィードバックについては、下記4をご覧ください。

2. 端末の権限を使う理由

権限利用目的データの保存場所
カメラなぞって描く動画を撮影するとき端末内のアプリ領域
写真ライブラリ（読み取り）なぞって描く動画を読み込むとき端末内のアプリ領域
写真ライブラリ（追加）完成したアニメーションを動画として保存するときお使いの「写真」アプリ
マイクアニメーションにお子さまの声を録音（アフレコ）するとき端末内のアプリ領域

各権限は、その機能を使うときにだけ求められます。許可しなくても、ほかの機能はそのまま使えます。権限を通じてアクセスした内容が端末の外に送られることはありません。

3. インターネット接続

インターネットに接続するのは次の場合だけです。リンクから動画を開くときにその動画をダウンロードする場合、買い切りプランの購入・復元のために Apple の App Store を利用する場合、そしてフィードバックを送る場合（下記4）です。動画のダウンロードはお使いの端末と動画のサーバーとの間だけで行われ、開発者を含む第三者に情報が渡ることはありません。ダウンロードした動画は端末の中だけに保存され、プロジェクトを削除すると一緒に削除されます。支払いはすべて Apple が処理し、開発者がお支払い情報を受け取ることはありません。

4. フィードバックの送信

サポート画面の「フィードバックを送る」からご意見を送ると、入力した内容（ご意見の種類、メッセージ、添付したスクリーンショット、返信用に入力したお名前・メールアドレス）と、アプリのバージョン、機種、OS のバージョン、言語設定が、Apple の iCloud（CloudKit）を通じて開発者に届きます。返信とアプリの改善にのみ使用し、送信しない限り何も送られません。お名前とメールアドレスの入力は任意です。送ったフィードバックの削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。フィードバックは保護者の方が送ってください。

5. 子どもの保護

Palang Book は、子どもが使うことを前提に作られています。子どもを含むどの利用者の個人情報も自ら収集することはなく、広告やソーシャル機能もありません。唯一のアプリ内課金である買い切りプランは、子どもがひとりでは通れない大人向けの確認（計算問題）の先にあります。

6. データの削除

すべてのデータは端末の中だけにあるため、アプリ内でプロジェクトを削除するか、アプリを削除すれば、関連するデータはすべて削除されます。開発者への削除依頼は必要ありません（ご自身で送ったフィードバックのみ例外で、上記4のとおりご依頼があれば削除します）。

7. ポリシーの変更

このポリシーを変更する場合は、このページに掲載し、施行日を更新します。
