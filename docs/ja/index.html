Palang Book

1枚ずつなぞって描けば、自分の絵が動き出す。

Palang Book は、iPad で遊べる子ども向けのパラパラアニメアプリです。うすい下絵を1枚ずつなぞって描き、再生ボタンを押すと、下絵は消えてお子さまが描いた線だけが動き出します。ボタンはすべて絵だけなので、まだ字が読めない小さなお子さまでも、指や Apple Pencil でひとりで遊べます。

できること

  • なぞって描ける10種類の下絵
    はずむボール、ぴょんぴょん跳ねるウサギ、空を飛ぶ鳥、泳ぐ魚、咲く花、チョウチョ、走る車、飛び立つロケット、カエル、かざぐるま。どのセットにも約20枚の下絵が入っています。前のページの絵がうっすら透けて見えるので、次の1枚もつなげて描きやすくなっています。
  • 自分の動画の上に描く
    カメラで撮った動画や「写真」アプリの動画、動画ファイルのリンクを読み込んで、その上からなぞって描けます。背景を隠すと、絵を描いたページだけが白い紙の上で再生されます。
  • まっさらなパラパラ帳
    下絵なしの白い紙に自由に描いて、ページをめくりながらオリジナルのパラパラマンガを作れます。
  • スタンプと色
    ハート、まる、しかく、さんかく、星、花、車、鳥のスタンプ（大きさは3段階）、10色の絵の具、3種類の筆の太さ。消しゴム、ひとつ戻る、ページをまるごと消すボタンもあります。
  • 声を録音
    マイクを押すと、アニメーションがくり返し再生されている間にお子さまの声を録音して、作品に入れられます。
  • 「写真」アプリに保存
    できあがったアニメーションは動画として「写真」アプリに保存されるので、家族にも見せられます。
  • 作品はすべて iPad の中に
    アカウント登録も広告も追跡もありません。描いた絵や録音した声が端末の外に出ることはありません。

無料で試せて、買い切りプランですべて開放

無料のままでも、なぞり描きの下絵3セット、作品3つの保存、動画の読み込み1回、白紙のパラパラ帳10ページまで、声の録音15秒までを使えます。買い切りプランは、一度購入すればすべての機能がずっと使えるようになります。サブスクリプションではなく、ファミリー共有にも対応しています。購入画面は、大人がかんたんな計算問題に答えないと開きません。
